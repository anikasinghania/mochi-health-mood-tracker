# Mochi Health Application for Mood Tracking

Author: Anika Singhania

### Description

This is a mood tracking application to pulse the queue of help tickets online. It features a dropdown menu of moods and a section to include a note. The bar chart below dynamically updates upon submission of the mood. The entry is then also added as a new row to the Google Sheet. Built with Python and Streamlit.
